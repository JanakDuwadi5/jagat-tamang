# Jagat Tamang - Artist Portfolio

This is the official portfolio website for Jagat Tamang, a painter and visual
artist based in Toronto, Canada. The site presents a curated collection of
original oil, acrylic, and charcoal paintings, with a focus on realism,
cultural identity, and emotional depth.

## About the site

Visitors can:

- Explore the full painting gallery.
- Open individual painting pages for a closer look.
- Learn more about Jagat's artistic practice and background.
- Send an enquiry about original works, commissions, or collaborations.

The site is designed as a calm, image-led gallery experience that works well on
mobile, tablet, and desktop screens. It is available at
[jagattamang.com](https://jagattamang.com).

## Technology

- Vue 3
- Vue Router
- Vite
- Tailwind CSS
- Cloudflare Pages deployment
